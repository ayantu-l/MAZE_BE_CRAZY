MAZE BE CRAZY

Maze Be Crazy is a browser-based, single-player maze survival game website created for Inspired by the maze survival of The Maze Runner, the project challenges players to navigate dangerous corridors, survive monster attacks and find the exit.

Features

- Six website pages: Home, Game, About, Register, Login and Rankings.
- Dark survival-themed interface with a shared stylesheet, responsive elements and an animated home-page introduction.
- Three maze levels with increasing enemy counts and movement speeds.
- Keyboard controlled player movement and shooting.
- Image based maze collision detection to stop movement through walls.
- Monsters that chase nearby players, attack at close range and can mutate.
- Weapon overheating and a temporary weapon jam when the heat limit is reached.
- Echo ability that temporarily reveals more of the maze, with a cooldown.
- Scoring system and a rankings interface.
- Registration and login interfaces with space for inline validation feedback.
