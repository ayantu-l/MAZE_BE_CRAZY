## MAZE BE CRAZY

Maze Be Crazy is a browser based, single player maze survival game website created for Inspired by the maze survival of The Maze Runner, the project challenges players to navigate dangerous corridors, survive monster attacks and find the exit.

## Game Features
- Three levels stone dungeon, mossy ruins and lava caves
- Monsters that chase and attack the player
- Shooting and health system
- Weapon overheating the gun jams for five seconds if it gets too hot
- Echo briefly reveals the maze but alerts monsters
- Sound mute and unmute button
- Registration login and saved high scores

Guests can play but they cannot save scores or access the Rankings page registered players can view rankings and save scores in browser local storage

For demonstration only this project stores account details locally do not register with a password you use elsewhere.

## Project Folders

- css/style.css layout and website design
- js/ website functions, registration, login, storage and rankings
- js/game/ game logic, player, monsters, collision, levels, animation and sound
- images/ characters, mazes and collision maps
- sounds/ game music and sound effects


## How to Run in VS Code
1. Open the complete MAZE_BE_CRAZY folder in Visual Studio Code.
2. Install the Live Server extension if needed.
3. Right click index.html and choose Open with Live Server.
4. The introduction and home page will open in your browser click play game to start

## Game Controls

- WASD or arrow keys move the player
- Spacebar shoot
- E activate Echo
- F fullscreen mode
- Esc return to level selection
- R or Enter return to level selection after game over or victory
